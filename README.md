# Playwright UI Automation

This is an ongoing project I am working on to improve my UI automation skills using Playwright and JavaScript. I practice regularly and add new test cases as I learn.

## What I'm Testing

**A/B Testing**
- Check page navigation.
- Verify the page heading and content.
- Test page reload.

**Add/Remove Elements**
- Add one or multiple buttons.
- Remove buttons and verify the changes.
- Add buttons again after removing them.

## Tools Used
- JavaScript
- Playwright
- Node.js
- Git and GitHub

## About This Project

I started this project to get more hands-on experience with Playwright. I am building it step by step, adding new scenarios as I practice, and improving my test-writing skills along the way.

I will continue updating this repository as I learn more.
